1
Apps Script 배포 (최초 1회)

2
수업 코드 결정 후 안내

예: 김체육-2반 · 화접중-3-1 · hjms-2-417
3
이 HTML 파일을 학생에게 배포
파일을 학교 홈페이지·클래스룸·QR코드로 공유하거나, USB로 나눠줘도 됩니다. 인터넷 연결만 있으면 로그인 없이 접속 가능합니다.
4
교사용 조회 페이지에서 확인
Apps Script 웹앱 URL을 브라우저에서 열면 교사용 조회 화면이 나타납니다. 수업 코드 입력 → 조회.

🚀 배포 방법 (Apps Script)

① Google 스프레드시트 생성
구글 드라이브에서 새 스프레드시트 만들기

② Apps Script 열기
확장 프로그램 → Apps Script

③ 파일 붙여넣기
Code.gs 내용을 편집기에 붙여넣기
파일 → 추가 → HTML → 교사용_조회 이름으로 저장 후 내용 붙여넣기

④ 웹앱으로 배포
배포 → 새 배포 → 유형: 웹 앱
실행 계정: 나 / 액세스: 모든 사용자(로그인 불필요)
→ 배포 → 웹앱 URL 복사

⑤ 학생용 HTML 수정
학생용.html 맨 위의 APPS_SCRIPT_URL 변수에 복사한 URL 붙여넣기

⑥ 권한 승인
처음 실행 시 "Google 계정 인증 필요" 팝업 → 고급 → 앱 이름(안전하지 않음) 이동 → 허용

⚠️ 교사 주의사항

· 수업 코드는 추측하기 어렵게 정하세요 (숫자 조합 추가 권장).
· 학기 종료 후 교사용 조회 화면에서 기록을 삭제해 주세요.
· 중요 기록은 구글 시트에서 직접 백업하세요.

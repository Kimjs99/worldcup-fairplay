# 🚀 배포 가이드 — 2026 월드컵 페어플레이 관찰 앱

> 이 문서는 학교 선생님이 **Google Apps Script + 구글 시트** 기반으로 앱을 배포하는 방법을 단계별로 안내합니다.  
> 학생은 **로그인 없이** 학생용.html 파일 하나만으로 기록을 제출할 수 있습니다.

---

## 📦 파일 목록

| 파일 | 용도 | 누가 사용 |
|------|------|-----------|
| `Code.gs` | Apps Script 백엔드 (제출 수신·저장·조회) | 선생님이 복사 → 붙여넣기 |
| `교사용_조회.html` | 제출 기록 조회 웹페이지 (Apps Script에 포함) | 선생님이 복사 → 붙여넣기 |
| `학생용.html` | 학생 관찰 기록 앱 (로그인 불필요) | 학생에게 배포 |

---

## ✅ 배포 절차 (최초 1회)

### 1단계. 구글 스프레드시트 만들기
1. [Google Drive](https://drive.google.com)에서 **새로 만들기 → Google 스프레드시트** 클릭
2. 시트 이름을 `페어플레이 관찰 기록` 등 원하는 이름으로 변경

---

### 2단계. Apps Script 열기
1. 스프레드시트 상단 메뉴: **확장 프로그램 → Apps Script**
2. 새 편집기 탭이 열립니다.

---

### 3단계. Code.gs 붙여넣기
1. 왼쪽 파일 목록에서 `Code.gs` 클릭
2. 기존 내용을 **전체 선택 후 삭제**
3. 제공된 `Code.gs` 파일의 전체 내용을 **붙여넣기**
4. **💾 저장** (Ctrl+S)

---

### 4단계. 교사용 조회 HTML 추가
1. 왼쪽 파일 목록 옆 **＋ 버튼 → HTML**
2. 파일 이름: `교사용_조회` (확장자 없이 입력)
3. 기존 내용을 전체 삭제 후 제공된 `교사용_조회.html` 내용 **붙여넣기**
4. **💾 저장**

---

### 5단계. 웹앱으로 배포하기
1. 오른쪽 상단 **배포 → 새 배포** 클릭
2. 유형 선택에서 **⚙️ 톱니바퀴 → 웹 앱** 선택
3. 설정:
   - **설명**: `월드컵 페어플레이 관찰` (임의 입력)
   - **실행 계정**: `나 (내 Google 계정)`
   - **액세스 권한**: `모든 사용자` ← **반드시 이 옵션으로 설정**
4. **배포** 클릭
5. **권한 승인** 팝업 → `권한 검토` → 구글 계정 선택 → `고급` → `(프로젝트명)(안전하지 않음)으로 이동` → `허용`
6. 🎉 **웹앱 URL 복사** (예: `https://script.google.com/macros/s/XXXXX/exec`)

> ⚠️ 이 URL이 제출 데이터를 받는 주소입니다. 안전하게 보관하세요.

---

### 6단계. 학생용 HTML에 URL 입력하기
1. `학생용.html` 파일을 **메모장** 또는 **VSCode**로 열기
2. 맨 위 스크립트 영역에서 아래 줄을 찾습니다:

```javascript
var APPS_SCRIPT_URL = "https://script.google.com/macros/s/여기에_배포URL_붙여넣기/exec";
```

3. `여기에_배포URL_붙여넣기` 부분을 복사한 URL로 교체:

```javascript
var APPS_SCRIPT_URL = "https://script.google.com/macros/s/AKfycbxABC123.../exec";
```

4. 파일 저장

---

### 7단계. 학생에게 배포하기

| 방법 | 설명 |
|------|------|
| **USB 배포** | `학생용.html` 파일을 USB에 담아 배포 → 로컬에서 실행 가능 |
| **학교 홈페이지** | 파일 업로드 후 링크 공유 |
| **Google Classroom** | 자료로 첨부 |
| **QR코드** | URL을 QR 변환 후 칠판에 출력 |

> 📌 학생은 **인터넷 연결**만 있으면 되며, **구글 계정 로그인이 필요 없습니다.**

## 🔑 수업 코드 운영 방법

수업 코드는 **데이터를 수업·학급별로 분리**하는 핵심 기능입니다.

### 코드 설계 예시

| 상황 | 권장 코드 | 이유 |
|------|-----------|------|
| 한 학교·한 교사 | `김체육-2반`, `김체육-3반` | 학급별 분리 |
| 여러 교사 | `김체육-2반`, `이체육-2반` | 교사별 분리 |
| 여러 학교 | `구리중-3-1`, `남양주중-3-1` | 학교별 분리 |
| 보안 강화 | `dpms-2-3-417` | 학교약칭+학급+임의숫자 |

### 수업 코드 자동 정규화 규칙
- 공백 · 따옴표 · 슬래시(`/ \ ' "`) → 하이픈(`-`)으로 자동 변환
- 대소문자 → 소문자로 통일
- 예: `김체육 2반` 입력 → `김체육-2반` 으로 저장
- 따라서 학생이 띄어쓰기를 실수해도 올바르게 매칭됩니다.

## 📊 제출 기록 확인 방법

### 방법 A — 교사용 조회 페이지 (추천)
1. 배포된 **웹앱 URL**을 브라우저에서 열기
2. 수업 코드 입력 → **조회** 버튼
3. 학생별 카드 형태로 기록 확인, 상세 보기 및 삭제 가능

### 방법 B — 구글 시트 직접 확인
1. 앞서 만든 구글 스프레드시트 열기
2. 수업 코드에 해당하는 시트 탭 클릭 (예: `기록_김체육-2반`)
3. 모든 제출 데이터가 행으로 쌓여 있음

> 💡 구글 시트에서는 필터·정렬·차트 기능을 활용해 학급 통계를 만들 수 있습니다.

---

## 🔄 앱 업데이트 시 재배포 방법

코드를 수정한 경우:
1. Apps Script 편집기에서 **배포 → 배포 관리**
2. 기존 배포 선택 → **✏️ 수정** → 버전: **새 버전**
3. **배포** → URL은 동일하게 유지됨 (학생용 HTML 수정 불필요)

## ❓ 자주 묻는 질문

**Q. 학생이 제출했는데 시트에 안 보여요.**
- Apps Script 배포 시 액세스 권한이 `모든 사용자`로 설정됐는지 확인
- 배포 후 권한 승인을 완료했는지 확인
- 학생용 HTML의 URL이 정확한지 확인 (복사 시 끝부분 잘림 주의)

**Q. 수업 코드를 바꿀 수 있나요?**
- 언제든 새 코드를 사용하면 됩니다. 기존 코드의 데이터는 그대로 유지됩니다.

**Q. 여러 반을 동시에 운영해도 되나요?**
- 네. 각 반마다 다른 수업 코드를 사용하면 자동으로 분리됩니다.

**Q. 데이터를 영구 삭제하려면?**
- 구글 시트에서 해당 시트 탭을 우클릭 → `삭제`

**Q. 학생용 HTML을 수정하지 않고 URL만 바꿀 방법이 없나요?**
- URL 파라미터 방식으로 전달할 수도 있으나, 보안상 HTML 직접 수정을 권장합니다.

---

## ⚠️ 보안 및 개인정보 주의사항

- 웹앱 URL을 아는 사람은 누구나 **POST로 데이터를 제출**할 수 있습니다.
- 수업 코드를 아는 사람은 해당 코드의 기록을 **조회**할 수 있습니다.
- 따라서:
  - 학생 이름 대신 **번호나 별칭** 사용 권장
  - 수업 코드는 **해당 학급 학생에게만** 공유
  - 학기 종료 후 구글 시트에서 **기록 삭제** 권장
  - 민감 정보(주민번호, 연락처 등)는 절대 입력하지 않도록 지도
